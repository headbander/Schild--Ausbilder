================================================================================
SETUP-SCHRITTE:
================================================================================

1. Xcode öffnen
2. File → New → Project → macOS → App
   - Name: TXTtoCSVConverter
   - Interface: SwiftUI
   - Language: Swift

3. Im Projekt-Navigator (links):
   - Erstelle Groups: Models, Views, Utils
   - Lösche die auto-erstellte ContentView.swift

4. Füge die 9 Swift-Dateien hinzu:
   - Drag & Drop in die entsprechenden Groups
   - ODER: Right-click → Add Files to "TXTtoCSVConverter"

5. Für jede Datei sicherstellen:
   - File Inspector (rechts) → Target Membership: ✓ TXTtoCSVConverter

6. Build (⌘B) und Run (⌘R)
